# 結論

## 4,000行未満のコードベース

WireGuardのコードは全体で4,000行未満と、IPsecやOpenVPNより非常に小さい規模です。そのため、脆弱性の発見や保守がしやすいという利点があります。

## マルチプラットフォーム

WireGuardはカーネル空間で動作するため高性能です。コードベースも小さく、幅広い機器で利用でき、将来にわたって信頼できるセキュリティ特性を提供します。

## 暗号鍵ルーティング

WireGuardは複雑な設定の代わりに、ピアの**公開鍵と許可されたIPアドレス**だけで接続を許可する単純な方式を使います。セキュリティ事故を防ぎ、管理もしやすくなります。

## 沈黙によるセキュリティ

WireGuardは通常、認証されていないパケットに応答しません。そのためネットワークスキャンが難しく、安全性が高まります。

## 補足：簡単なインストール方法

> 非公式の簡単インストールスクリプト[Nyr/wireguard-install](https://github.com/Nyr/wireguard-install)も利用できます。

```
$ wget https://git.io/wireguard -O wireguard-install.sh && bash wireguard-install.sh
```
